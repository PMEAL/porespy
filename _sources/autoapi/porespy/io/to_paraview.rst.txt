porespy.io.to_paraview
======================

.. py:function:: porespy.io.to_paraview(im, filename, phase=2)

   Converts an array to a paraview state file.

   :param im: The image of the porous material.
   :type im: ndarray
   :param filename: Path to output file.
   :type filename: str
   :param phase: The desired phase of output image where phase = 0 represent the
                 pore phase, phase = 1 represents the solid phase, and phase= 2 is
                 the whole domain. The default value is 2.
   :type phase: str

   .. rubric:: Notes

   Outputs an pvsm file that can opened in Paraview.

   .. rubric:: Examples

   `Click here
   <https://porespy.org/examples/io/reference/to_paraview.html>`__
   to view online example.
