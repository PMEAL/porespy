porespy.io.open_paraview
========================

.. py:function:: porespy.io.open_paraview(filename=None, im=None, **kwargs)

   Open a paraview state file or image directly in paraview.

   :param filename: Path to input state file.
   :type filename: str
   :param im: An image to open directly.  If no filename given, then this image is
              sent to ``to_paraview`` and a state file is created with a random name.
              Any additional keyword arguments are sent to ``to_paraview``.
   :type im: ndarray

   .. rubric:: Examples

   `Click here
   <https://porespy.org/examples/io/reference/open_paraview.html>`__
   to view online example.
