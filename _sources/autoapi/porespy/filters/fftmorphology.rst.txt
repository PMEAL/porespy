porespy.filters.fftmorphology
=============================

.. py:function:: porespy.filters.fftmorphology(im, strel, mode='opening')

   Perform morphological operations on binary images using fft approach for
   improved performance

   :param im: The binary image on which to perform the morphological operation
   :type im: ndarray
   :param strel: The structuring element to use.  Must have the same dims as ``im``.
   :type strel: ndarray
   :param mode: The type of operation to perform.  Options are 'dilation', 'erosion',
                'opening' and 'closing'.
   :type mode: string

   :returns: **image** -- A copy of the image with the specified moropholgical operation applied
             using the fft-based methods available in ``scipy.signal.fftconvolve``.
   :rtype: ndarray

   .. rubric:: Notes

   This function uses ``scipy.signal.fftconvolve`` which *can* be more than
   10x faster than the standard binary morphology operation in
   ``scipy.ndimage``.  This speed up may not always be realized, depending
   on the scipy distribution used.

   .. rubric:: Examples

   `Click here
   <https://porespy.org/examples/filters/reference/fftmorphology.html>`_
   to view online example.
