porespy.generators.insert_shape
===============================

.. py:function:: porespy.generators.insert_shape(im, element, center=None, corner=None, value=1, mode='overwrite')

   Inserts sub-image into a larger image at the specified location.

   If the inserted image extends beyond the boundaries of the image it will
   be cropped accordingly.

   :param im: The image into which the sub-image will be inserted
   :type im: ndarray
   :param element: The sub-image to insert
   :type element: ndarray
   :param center: Coordinates indicating the position in the main image where the
                  inserted imaged will be centered.  If ``center`` is given then
                  ``corner`` cannot be specified.  Note that ``center`` can only be
                  used if all dimensions of ``element`` are odd, otherwise the meaning
                  of center is not defined.
   :type center: tuple
   :param corner: Coordinates indicating the position in the main image where the
                  lower corner (i.e. [0, 0, 0]) of the inserted image should be anchored.
                  If ``center`` is given then ``corner`` cannot be specified.
   :type corner: tuple
   :param value: A scalar value to apply to the sub-image.  The default is 1.
   :type value: scalar
   :param mode: If 'overwrite' (default) the inserted image replaces the values in the
                main image.  If 'overlay' the inserted image is added to the main
                image.  In both cases the inserted image is multiplied by ``value``
                first.
   :type mode: string

   :returns: **im** -- A copy of ``im`` with the supplied element inserted.
   :rtype: ndarray

   .. rubric:: Examples

   `Click here
   <https://porespy.org/examples/generators/reference/insert_shape.html>`__
   to view online example.
