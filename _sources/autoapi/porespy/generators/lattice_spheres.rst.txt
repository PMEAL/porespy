porespy.generators.lattice_spheres
==================================

.. py:function:: porespy.generators.lattice_spheres(shape: List, r: int = 5, spacing: int = None, offset: int = None, smooth: bool = True, lattice: Literal['sc', 'tri', 'fcc', 'bcc'] = 'sc')

   Generate a cubic packing of spheres in a specified lattice arrangement.

   :param shape: The size of the image to generate in [Nx, Ny, Nz] where N is
                 the number of voxels in each direction. For a 2D image, use
                 [Nx, Ny].
   :type shape: list
   :param radius: The radius of spheres (circles) in the packing.
   :type radius: int
   :param spacing: The spacing between unit cells. If the spacing is too small then
                   spheres may overlap. If an ``int`` is given it will be applied
                   in all directions, while a list of ``int`` will be interpreted
                   to apply along each axis.
   :type spacing: int or List[int]
   :param offset: The amount offset to add between sphere centers and the edges of
                  the image. A single ``int`` will be applied in all directions,
                  while a list of ``int`` will be interpreted to apply along each
                  axis.
   :type offset: int or List[int]
   :param smooth: If ``True`` (default) the outer extremities of the sphere will
                  not have the little bumps on each face.
   :type smooth: bool, default=True
   :param lattice: Specifies the type of lattice to create. Options are:

                   ======= ===============================================================
                   option  description
                   ======= ===============================================================
                   'sc'    Simple cubic (default), works in both 2D and 3D.
                   'tri'   Triangular, only works in 2D
                   'fcc'   Face centered cubic, only works in 3D
                   'bcc'   Body centered cubic, only works on 3D
                   ======= ===============================================================
   :type lattice: str

   :returns: **image** -- A boolean array with ``True`` values denoting the pore space.
   :rtype: ndarray

   .. rubric:: Notes

   For 2D images, 'sc' gives a square lattice and both 'fcc' and
   'bcc' give a triangular lattice.

   .. rubric:: Examples

   `Click here
   <https://porespy.org/examples/generators/reference/lattice_spheres.html>`__
   to view online example.
