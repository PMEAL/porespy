porespy.visualization.show_panels
=================================

.. py:function:: porespy.visualization.show_panels(im, rc=[3, 3], axis=0)

   Show slices of a 3D image as a 2D array of panels.

   :param im: The 3D image to visualize
   :type im: ndarray
   :param rc: The number of rows and columns to create
   :type rc: list of ints
   :param axis: The axis along which to create the slices
   :type axis: int

   :returns: **fig, ax**
   :rtype: Matplotlib figure and axis handles
