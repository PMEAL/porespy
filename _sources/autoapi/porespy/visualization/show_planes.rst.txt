porespy.visualization.show_planes
=================================

.. py:function:: porespy.visualization.show_planes(im, spacing=10)

   Create a quick montage showing a 3D image in all three directions

   :param im: A 3D image of the porous material
   :type im: ndarray
   :param spacing: Controls the amount of space to put between each panel
   :type spacing: int (optional, default=10)

   :returns: **image** -- A 2D array containing the views.  This single image can be viewed using
             `matplotlib.pyplot.imshow`.
   :rtype: ndarray

   .. rubric:: Examples

   `Click here
   <https://porespy.org/examples/visualization/reference/show_planes.html>`__
   to view online example.
