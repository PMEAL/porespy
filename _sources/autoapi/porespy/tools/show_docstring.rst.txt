porespy.tools.show_docstring
============================

.. py:function:: porespy.tools.show_docstring(func)

   Fetches the docstring for a function and returns it in markdown format.

   Useful for printing in a Jupyter notebook.

   :param func: Handle to function whose docstring is desired
   :type func: object

   :returns: **md** -- A string with the markdown syntax included, suitable for printing
             in a Jupyter notebook using the ``IPython.display.Markdown``
             function.
   :rtype: str
