porespy.tools.remove_overlaps
=============================

.. py:function:: porespy.tools.remove_overlaps(slices, overlap, shape)

   Removes overlap from slices generated by the `get_slices_<x>` functions.

   Given a list of slices which, this returns a new list of slices into the original
   image with the overlap removed, as well as a list of slices into the sliced
   images also with overlap removed.

   :param slices: The slice objects with overlaps added
   :type slices: list of slice objects
   :param overlap: The amount of overlap in each direction. If a scalar is provide then it is
                   assumed this overlap applies in all directions.
   :type overlap: int or list of ints
   :param shape: The shape of the original image to which the slices apply
   :type shape: list of ints
