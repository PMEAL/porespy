porespy.tools.ps_rect
=====================

.. py:function:: porespy.tools.ps_rect(w, ndim)

   Creates rectilinear structuring element with the given size and
   dimensionality

   :param w: The desired width of the structuring element
   :type w: scalar
   :param ndim: The dimensionality of the element, either 2 or 3.
   :type ndim: int

   :returns: **strel** -- A numpy array of the structuring element
   :rtype: ndarray

   .. rubric:: Examples

   `Click here
   <https://porespy.org/examples/tools/reference/ps_rect.html>`__
   to view online example.
