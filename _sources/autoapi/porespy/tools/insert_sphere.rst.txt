porespy.tools.insert_sphere
===========================

.. py:function:: porespy.tools.insert_sphere(im, c, r, v=True, overwrite=True)

   Inserts a sphere of a specified radius into a given image

   :param im: Image into which the sphere should be inserted
   :type im: array_like
   :param c: The [x, y, z] coordinate indicating the center of the sphere
   :type c: array_like
   :param r: The radius of sphere to insert
   :type r: int
   :param v: The value to put into the sphere voxels.  The default is ``True``
             which corresponds to inserting spheres into a Boolean image.  If
             a numerical value is given, ``im`` is converted to the same type as
             ``v``.
   :type v: int
   :param overwrite: If ``True`` (default) then the sphere overwrites whatever values are
                     present in ``im``.  If ``False`` then the sphere values are only
                     inserted into locations that are 0 or ``False``.
   :type overwrite: boolean

   :returns: **image** -- The original image with a sphere inerted at the specified location
   :rtype: ndarray

   .. rubric:: Examples

   `Click here
   <https://porespy.org/examples/tools/reference/insert_sphere.html>`__
   to view online example.
