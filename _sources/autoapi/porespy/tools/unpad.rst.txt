porespy.tools.unpad
===================

.. py:function:: porespy.tools.unpad(im, pad_width)

   Remove padding from a previously padded image given original pad widths

   :param im: The padded image from which padding should be removed
   :type im: ndarray
   :param pad_width: The amount of padding previously added to each axis. This should be
                     the same as the values used to add original padding. Refer to
                     ``numpy.pad`` documentation for more details.
   :type pad_width: int or list of ints

   .. rubric:: Examples

   `Click here
   <https://porespy.org/examples/tools/reference/unpad.html>`__
   to view online example.
