porespy.tools.ps_disk
=====================

.. py:function:: porespy.tools.ps_disk(r, smooth=True)

   Creates circular disk structuring element for morphological operations

   :param r: The desired radius of the structuring element
   :type r: float or int
   :param smooth: Indicates whether the faces of the sphere should have the little
                  nibs (``True``) or not (``False``, default)
   :type smooth: boolean

   :returns: **disk** -- A 2D numpy bool array of the structring element
   :rtype: ndarray

   .. rubric:: Examples

   `Click here
   <https://porespy.org/examples/tools/reference/ps_disk.html>`__
   to view online example.
