porespy.tools.results_to_df
===========================

.. py:function:: porespy.tools.results_to_df(obj)

   A helper function to convert Results objects to pandas DataFrames.

   :param obj: The custom Results object to be converted to a DataFrame
   :type obj: porespy.tools.Results

   :returns: **df** -- A DataFrame containing all of the custom attributes on the inputted
             Results object.
   :rtype: pandas.DataFrame

   .. rubric:: Notes

   The contents of the Results object are expected to be DataFrame compatible
   data types.
